# 奇妙な博物館 / 第0号館

奇妙な実話や科学の発見を、三択クイズで調べる小さな博物館です。6点の正式展示で遊べます。発掘室には、次の展示に選ぶための候補40点を収録しました。

## 遊ぶ

1. [第0号館](index.html)を開き、好きな展示を選ぶ。
2. 解説を読んで三択に答え、6つの収蔵印を集める。間違えても収蔵印は手に入ります。
3. 全6点を調べると、第7展示室が開く。
4. [発掘室](curation.html)で候補を検索し、クイズに答えて気に入った展示を選ぶ。選択結果はJSONファイルに書き出せます。

`index.html` と `curation.html` は、それぞれブラウザで直接開けます。アプリのインストールは不要です。

## 自分の展示を寄贈する

第0号館の「展示を寄贈する」に、発見した話と出典URLを入力します。寄贈品は未検証として表示され、正式展示とは別に保管します。

回答記録と寄贈品、発掘室で選んだ候補は、ブラウザの `localStorage` に保存します。保存に対応していない環境では画面に注意が出ます。記録を残す場合はJSONを書き出してください。別のブラウザで続ける場合、第0号館の「記録を復元」で戻せます。発掘室の候補リストは書き出し専用です。

アプリは記録を運営サーバーに送信しません。出典リンクを開けば、リンク先のWebサイトにはアクセスします。端末やブラウザを変えると保存状態は共有されません。

## 展示と出典

正式展示6点には、それぞれ出典を掲載しています。候補40点は出典URLを掲載していますが、全件の記述を個別に照合したわけではありません。候補の説明、三択、出典URL、注記は `exhibit_candidates.json` が正本です。事実として観測・記録された内容と、研究者の推定を区別して記載します。出典一覧は [CANDIDATES.md](CANDIDATES.md) を参照してください。

候補を直した場合は、次のコマンドで発掘室と出典一覧を作り直します。

```bash
python build_curation.py
```

`curation.html` と `CANDIDATES.md` は生成物です。個別に書き換えず、データを直してから再生成します。
