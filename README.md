# 奇妙な博物館 / 第0号館

奇妙な実話や科学の発見を三択クイズで調べる、ブラウザ用の小さな博物館です。第0号館には正式展示6点、発掘室には次の展示候補40点があります。

## 遊び方

1. [第0号館](index.html)で展示を選び、説明を読んで三択に答えます。間違えても収蔵印は手に入ります。
2. 6点すべてを調べると、秘密の第7展示室が開きます。
3. [発掘室](curation.html)では40件を検索し、クイズに答え、気に入った展示を収蔵候補に選べます。選んだ候補はJSONファイルに書き出せます。

ブラウザでHTMLを開いて遊べます。アプリのインストールは不要です。

## 展示を寄贈する

第0号館の「展示を寄贈する」に、見つけた話と出典URLを入力できます。寄贈品には「未検証」と表示し、正式展示とは別に保管します。

回答、寄贈品、発掘室で選んだ候補は、使用中のブラウザの `localStorage` に保存します。端末やブラウザを変えても、自動では引き継がれません。第0号館の記録はJSONで書き出し、「記録を復元」で読み込めます。発掘室の候補リストは書き出し専用です。

保存できない環境では、画面の注意に従ってJSONを書き出してください。アプリはこれらの記録をサーバーへ送りません。出典リンクを開いた場合は、リンク先のサイトに接続します。

## 展示の根拠

正式展示6点には、それぞれ出典へのリンクを付けています。発掘室の40件にも出典と注記を付けていますが、説明と資料の対応を全件確認したわけではありません。各候補の検証状態は展示カードに表示します。

候補データの正本は `exhibit_candidates.json` です。説明、クイズ、出典を修正したら次のコマンドで表示ページと出典一覧を再生成します。

```bash
python build_curation.py
```

`curation.html` と `CANDIDATES.md` は生成物です。出典一覧は [CANDIDATES.md](CANDIDATES.md) にあります。
